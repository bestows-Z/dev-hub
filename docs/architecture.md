# 系统架构

DevHub 将公开页面、管理台、HTTP API、数据服务和可执行项目预览分开部署。PostgreSQL 是业务数据的事实来源，其他存储承担文件、检索、限流和分析任务。

## 进程与职责

| 进程 | 职责 | 权限 |
| --- | --- | --- |
| Web | 文章阅读、项目与商品展示、账户和独立管理台 | 无数据库或 Docker 凭证 |
| API | 鉴权、内容、订单、上传、检索、任务排队 | PostgreSQL、MinIO、Redis 等服务连接 |
| 预览工作进程 | 领取管理员提交的项目任务 | PostgreSQL、MinIO、本机 Docker |
| 项目容器 | 运行已审查的前后端项目 | 独立网络、资源限制、无主站凭证 |

管理员在管理台上传完整项目 ZIP 后，API 仅保存文件并写入任务表。工作进程领取任务，调用本地运行器构建和启动容器。API 本身不需要 Docker Socket。站内预览入口由 API 根据项目发布状态与运行端口代理。

## 数据边界

- **PostgreSQL：** 用户、文章、评论、友链、项目、商品、订单、相册元数据、封面媒体记录、预览任务。
- **MinIO：** 头像、封面、相册照片、静态预览 ZIP 展开文件和完整项目 ZIP。
- **Redis：** 文章助手按访客 IP 的共享限流。
- **Elasticsearch：** 已发布文章的全文索引。启动时从 PostgreSQL 重建；不可用时回退数据库查询。
- **RabbitMQ → MongoDB：** 匿名公开页面访问事件。后台展示近七天趋势；事件不含访客 IP，MongoDB 中的事件按保留期清理。

## 鉴权与内容权限

目前普通用户可管理自己的资料、提交评论与友链申请、查看和取消自己的待付款订单。管理员可管理全站内容。公开注册不会获得管理员身份；提升管理员须在服务器本地执行命令。作者申请、多人写作和逐篇归属权限仍在开发，不能把当前管理员编辑权限授予普通用户。

业务 API 使用 /api/v1 前缀。登录令牌保存在当前浏览器标签页的 sessionStorage；退出后清除。公开项目预览和文章助手只读取已发布内容。

## 文件与预览安全

封面和头像上传会检查大小、文件格式、像素范围并重新编码，随后使用服务器生成的对象键保存到 MinIO。项目静态 ZIP 校验路径、文件类型与大小；完整项目 ZIP 还校验目录和 Compose 结构。上传 ZIP 本身不启动代码，只有管理员提交预览任务后工作进程才会构建。

预览容器不挂载主站数据库凭证、Docker Socket或宿主目录，使用只读根文件系统、CPU、内存和进程限制。网关只向 127.0.0.1 发布端口，由主 API 转发给访问者。Docker 构建会处理项目 Dockerfile，因此只能运行站长审查过的项目；不受信任的第三方项目需要更强的机器级隔离。

## 订单流程

商品价格和库存以数据库为准。登录用户创建订单时，事务完成价格计算和库存预留；订单归属与通知邮箱由服务端从用户身份写入。待付款订单可由用户取消并退回库存；管理员可处理后续状态。目前没有在线支付或自动邮件发送。
